        Linking your game

        1. Run SNI or QUsb2Snes, not both. They use the same port, so the second one to start says the port is already in use. If you use an auto-tracker you already have one of them. Otherwise get SNI, unzip it, and run sni.exe. It sits in the tray; there is nothing to configure. A web page cannot talk to an emulator by itself, NWA or otherwise, so this is the one program you need.
        2. Start your game the way your tracker needs it.
          snes9x-nwa, bsnes-plusNothing to do. SNI and QUsb2Snes find NWA emulators by themselves.
          RetroArchSettings, Network, Network Commands: on (port 55355).
          BizHawk, snes9x-rrOpen the Lua console and load Connector.lua from SNI's lua folder.
          FXPak Pro / SD2SNESUSB cable in, console on.
        3. Come back here. This page finds the game on its own within a few seconds. If the browser asks whether this site may reach devices or apps on your local network, allow it: the game is on your PC, and that is the only way a web page can reach it.

        Good to know

        This page reads your inventory bytes and the game module every half second, and the HUD strip cells it draws over. It writes items, the run flag for the boots, the bow and arrow bytes, and the HUD strip. Nothing else is read or written, and nothing leaves your PC but the item names it finds.

        One game link per player: linking on a second browser, or with the desktop app, takes over from this one. Works in Chrome, Edge and Firefox. Safari does not let a web page talk to a program on the same computer.
